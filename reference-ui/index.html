🔁 Define Shift Patterns
A pattern is a repeating cycle (e.g. MMAANNOO = 2 Morning, 2 Afternoon, 2 Night, 2 Off). Use shift codes separated by nothing. Cycle length = number of characters/codes.
📋 Pattern Reference
MMAANNOO — 2M 2A 2N 2Off (standard 8-day cycle)
NNOO — 2 Nights then 2 Off
GGGGGGGO — 6 General + 1 Off (weekly)
MMMMMMO — 6 Morning + 1 Off
AAAAAAO — 6 Afternoon + 1 Off
NNNOO — 3 Nights then 2 Off
DEP — Deputation (marks all days as SOD)
FLEXI — All days Flexi Shift
CUSTOM — Enter day-by-day manually

👤 Assign Staff to Shift Patterns
Assign each active staff member to a shift pattern and a start offset (which day of the cycle they begin on). Staff on leave this month will override pattern assignments for leave days.
ⓘ How does "Cycle Start Day" work? (click to expand)

What it means: a shift pattern like Morning → Evening → Night → Off repeats on a fixed cycle. "Cycle Start Day" is simply which position in that cycle a staff member begins on, so not everyone is scheduled for the same shift on the same day — the whole point of a rotation.

Example 1 — a fresh cycle:

Pattern is Morning → Evening → Night → Off, and Staff A's Cycle Start Day = 0 (the beginning). Day 1 of the roster = Morning, Day 2 = Evening, Day 3 = Night, Day 4 = Off, then it repeats: Day 5 = Morning again. Staff B with Cycle Start Day = 2 starts two steps further along: Day 1 = Night, Day 2 = Off, Day 3 = Morning, and so on — this is what spreads staff across different shifts on the same day instead of everyone doing the same thing at once.

Example 2 — interaction with "Continue from Previous Roster":

If last month ended on a Wednesday with Staff A on Evening, and "Continue from Previous Roster" is switched ON when generating next month, Thursday is calculated as the next step in the cycle after Evening — i.e. Night — not restarted from the beginning of the pattern. The Cycle Start Day value you set here is only used as the STARTING point the very first time a pattern is assigned to someone; once "Continue from Previous Roster" is in use, the actual previous month's real shifts take over as the reference point instead.

ℹ️ How Freq/month Tasks Are Calculated
Enter the manpower needed for one occurrence of the task (per layover, per weekly check, per A-check, etc). Given the frequency/month, the engine works out how many can realistically fall on the same day (occurrences ÷ days in month, rounded up) and multiplies that by your per-task manpower to get the concurrent requirement used for shift coverage.
